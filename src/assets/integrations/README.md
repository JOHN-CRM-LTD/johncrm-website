These channel and file assets are extracted from the existing homepage product story
(`src/app/product-story/story.html`) to keep the integration page visually consistent.
Webchat and WhatsApp retain the original supplied artwork. The document SVGs retain
the homepage's PDF, Excel, PowerPoint and Word illustrations, with their text styling
embedded for standalone rendering. Excel content is imported via CSV export and
PowerPoint content via PDF export, as labelled in the UI.
