# Product campaign artwork

Created with the built-in Image Gen tool. The images are production assets, derived from coordinated page concepts. Original generated PNGs remain in the Codex generated_images folder; these WebP versions use quality 88.

Visual system: warm paper #f7f5f0, midnight teal #102a32, slate #62747b, accent #216d89. Inter typography; 24px desktop hero image radius; 8px buttons. Photography has no tint or overlay. UI, conversation previews, workflow and coupon text are rendered in React.

The existing JOHN CRM logo and footer take precedence over the concept’s illustrative branding. Concept-only unsupported provider names were removed. Examples use fictional conversations and offers.
